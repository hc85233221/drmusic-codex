# DrMusic 吉他和弦譜

讀取使用者指定的譜頁。若同一頁兼有五線譜與和弦，依使用者指定的樂器選擇轉錄內容。需要鋼琴雙手音符或處理 .drm 時使用 drmusic-score。

## 朋友分享的樂譜

使用者要把朋友分享的譜匯入自己的曲庫時，以接收者的 DrMusic 連線呼叫 `drm_import_exchange({url})`，傳入完整的 AI 交換連結。收到 .drm 檔先看檔首；DRMX1. 是可跨帳號匯入的交換檔。觀看連結與原圖另有用途，詳見[分享連結與檔案辨識](../drmusic-score/references/exchange.md)。

## 轉錄與核對

依[吉他檔案規格](references/guitar.md)建立吉他譜。按原頁順序保留段落、每行歌詞、和弦與歌詞的對應位置。分開讀取和弦列與歌詞列：把和弦對齊它落下的字或字間，逐一回看行首、行中、行尾與無詞小節。保留斜線低音、升降記號、延伸音、同位置的多個和弦，以及前奏、間奏、反覆和刷法標記。多段歌詞共用和弦時，按原譜核對各段實際對位。

分別記錄原調、演奏調與 Capo。拍號、拍速、時值或指法沒有標示時保持缺省。和弦名稱不足以推得主旋律或完整節奏。遇到裁切、字跡不清或和弦歸屬不明，指出頁碼、段落與行，先保留草稿並請使用者確認。

## 同頁有方框數字與旋律簡譜時

先辨認數字所在的列。逐個框讀取和弦級數，連同框內的升降、大小寫、延伸音與斜線低音抄錄。一頁可同時有框內和弦、框外的旋律音和歌詞對位。用原圖的框、排列與記譜特徵定位：旋律列的高低八度點、短音底線、附點與休止屬旋律，不輸入吉他和弦列。框線不清時可用相鄰框、同欄與段落對照；無法辨明的局部就在原稿位置標出疑義。

轉換前找出該處生效的譜面調性。原唱調、建議演唱調、Capo 與實際換調標示各有用途。依記號落點切換調性，留意同一行或小節內的和弦。分開計算根音與斜線後低音的級數，再保留 chord quality 與延伸音。緊跟級數的升降是對該調內音級移動半音；和弦延伸音前的升降則修飾延伸音。轉錄後從本 Skill 目錄執行 `node scripts/read-chords.mjs "/path/to/score.json"`，逐框對回原符號、普通和弦、低音與歌詞位置；原文歧義會改變和聲時，先保留原形核對。[欄位與自編對照](references/guitar.md)

## 對應的 YouTube 影片

使用者已提供與這份譜相符的 YouTube 影片時，優先採用該網址。若自行尋找，先打開影片頁核對曲名、演出者，以及譜上有標示的版本，優先使用能辨識來源的官方演出或發行錄音。只有可信的單支影片才填入 `score.youtubeUrl`，再用原有吉他工具製檔或直接上傳。若曲名相同但演出者不明、提供的連結明顯不符，或無法查證自行找到的影片，就省略該欄位並照常匯入。曲主可稍後在樂譜頁貼上網址。

## 簽發及匯入

本機 MCP 先用 drm_connect 取得同機配對頁，核對帳號並保持分頁開啟。Sites 外掛沿用已驗證的帳號。檢查可用的吉他工具後再操作。

- 要求製作吉他檔時，使用 drm_package_guitar_score，將回傳的 package 原樣寫成 UTF-8，使用回傳的 .drmg 檔名。
- 要求製檔並匯入時，先交付檔案，再將同一個 package 送入 drm_import_guitar_package。收到既有 .drmg 時，讀取完整 UTF-8 封裝，交由原簽發帳號匯入。
- 僅要求直接上傳時，使用 drm_publish_guitar_score。同一次操作沿用相同 requestId。核對回傳的樂譜 ID 與連結，傳輸中斷時先查 drm_list_scores 確認結果。
- 單張私人 JPEG 或 PNG 可用樂譜 ID 呼叫 `drm_attach_original`，上限為 768 KiB。移轉獲授權的舊庫原檔，或保存 768 KiB 以內的本機 PDF 時，用 `drm_store_private_attachment` 依原始順序逐檔儲存，核對回傳的長度及 SHA-256。本機多張圖片或較大的 PDF 可經曲主已連接的配對移轉器逐檔傳送。單獨製檔時保留原圖，待匯入取得 ID 後再附上。
