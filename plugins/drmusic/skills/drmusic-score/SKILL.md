# DrMusic 鋼琴譜匯入

吉他和弦歌詞譜或 .drmg 檔請使用 drmusic-guitar-score。

使用已連接的 DrMusic 工具。第一次使用外部 MCP 橋接器時，呼叫 `drm_connect`，讓使用者在同一台電腦的配對頁確認自己的帳號。Codex 或 ChatGPT 的 Sites 外掛直接使用登入身分。

## 鋼琴譜照片或 PDF

1. 讀取這次指定的所有譜頁。依原譜核對譜號、調號、拍號、速度、左右手、和弦、延音與反覆。影像模糊時指出頁碼、小節與需要補拍的位置。缺頁或無法辨讀音符時先保留待確認稿。
2. 將音符寫成 [樂譜格式](references/score.md)。逐小節核對雙手起點和時值，檢查首尾、反覆展開後的小節總數與試聽長度。清楚告知為了播放而選用的假設速度。可讀資料留在使用者的工作階段。
3. 使用者要求上傳時，呼叫 `drm_publish_score`，傳入 score。對同一次工作重試請沿用相同的 requestId。核對回傳的 id 與網址；若傳輸中斷，先用 `drm_list_scores` 核對帳號中的結果。使用者提供單張譜照時，以該樂譜的 `id` 呼叫 `drm_attach_original` 私下保存原圖。每曲有一個原譜圖檔欄位，多頁來源可將全部頁面排成一張可辨讀的長圖，並保留原件。MCP 附圖支援 768 KiB 以內的 PNG/JPEG，超過時，先以保留可讀性的 JPEG 或 PNG 副本縮小，再經 MCP 附上。若大小與清晰度無法兼顧，說明原圖保存狀態並保留原件。
4. 若只要求檔案，改呼叫 `drm_package_score`。把回傳的完整 package 字串寫入 filename 指定的 UTF-8 檔案，不加引號或 Markdown。使用者之後可將這個檔案交給 AI，透過簽發時使用的帳號匯入。
5. 告知完成的曲名、小節數及可直接開啟的樂譜網址。分享給朋友由使用者在樂譜頁建立分享連結。

## 既有的 .drm 檔

使用者要求匯入 .drm 檔時，使用配對的 DrMusic 帳號，將指定的原檔完整讀為 UTF-8 文字，去除兩端空白，保留中間內容原樣。呼叫 `drm_import_package`，將該完整字串放入工具的 `package` 欄位。原樣重送同一封裝會取得同一份樂譜。若遭拒，依服務回覆說明原因，例如請使用者確認目前的帳號是否為原簽發帳號。

成功後回報工具傳回的樂譜連結。需要核對曲名時，透過 `drm_list_scores` 查詢傳回的樂譜 ID。
