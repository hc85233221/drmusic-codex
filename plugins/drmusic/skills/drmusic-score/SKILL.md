# DrMusic 樂譜匯入

使用已連接的 DrMusic 工具。第一次使用外部 MCP 橋接器時，呼叫 `drm_connect`，讓使用者在同一台電腦的配對頁確認自己的帳號。Codex 或 ChatGPT 的 Sites 外掛直接使用登入身分。

1. 讀取這次指定的所有譜頁。依原譜核對譜號、調號、拍號、速度、左右手、和弦、延音與反覆。影像模糊時指出頁碼、小節與需要補拍的位置。缺頁或無法辨讀音符時先保留待確認稿。
2. 將音符寫成 [樂譜格式](references/score.md)。逐小節核對雙手起點和時值，檢查首尾、反覆展開後的小節總數與試聽長度。清楚告知為了播放而選用的假設速度。可讀資料留在使用者的工作階段。
3. 使用者要求上傳時，呼叫 `drm_publish_score`，傳入 score。對同一次工作重試請沿用相同的 requestId。核對回傳的 id 與網址；若傳輸中斷，先用 `drm_list_scores` 核對帳號中的結果。使用者上傳單張譜照時，以該樂譜的 `id` 呼叫 `drm_attach_original` 私下保存原圖。每曲有一個原譜圖檔欄位，多頁來源可將全部頁面排成一張可辨讀的長圖，並保留原件。MCP 附圖支援 768 KiB 以內的 PNG/JPEG，超過時提供該曲的「附上原譜」入口（上限 8 MiB），清楚交代保存狀態。
4. 若只要求檔案，改呼叫 `drm_package_score`。把回傳的完整 package 字串寫入 filename 指定的 UTF-8 檔案，不加引號或 Markdown。使用同一帳號的網站匯入。服務端持有封裝金鑰；上傳以服務端驗證結果為準。
5. 告知完成的曲名、小節數及可直接開啟的樂譜網址。分享給朋友由使用者在樂譜頁建立分享連結。
