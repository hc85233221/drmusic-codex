# 把朋友分享的數位譜存入自己的曲庫

適用於鋼琴、獨立簡譜、吉他與鼓譜。先依使用者意圖選入口。只說要看譜時開啟觀看連結；明確要「匯入我的曲庫」時使用接收者自己的已登入 DrMusic 連線。本機橋接器需要配對時，以 `drm_connect` 開啟配對頁，由接收者確認帳號。使用 Google 或 Apple 的接收者由網站的「使用 ChatGPT 登入」進入自己的曲庫。Facebook 只有在網站提供該入口且站台允許進入時才能使用。先確認自己的曲庫，再於同一登入階段核對配對頁顯示的會員並按下連接。網站以會員身分識別曲庫，電子郵件相同仍可能對應不同曲庫。保持配對頁開啟。內建 ChatGPT／Sites 工具使用當前工作階段的站台身分，本機 Codex、Claude Code 或其他 stdio 橋接器則使用實際配對的網站會員。無法確認兩者是同一曲庫時，先確認或重配對再匯入。

| 收到的內容 | 操作 |
| --- | --- |
| 同一 DrMusic 站的 `/api/exchanges/<64位小寫十六進位字串>.drm` | 將使用者貼的完整網址傳給 `drm_import_exchange({url})`。即使訪客瀏覽器顯示 Sites 登入頁，已配對的工具仍能直接按網址查找交換快照，無須先擷取頁面或下載檔案。 |
| 交換用 .drm，開頭為 `DRMX1.` | 讀取完整 UTF-8 檔，去除首尾空白，以 `drm_import_exchange({package})` 傳入完整字串。只帶 url 或 package 其中之一。 |
| `/?share=…` 或 `/?score=…` | 前者是觀看連結，後者是曲庫入口。要跨帳號匯入，請分享者從原曲取得「給朋友 AI 匯入」連結或交換檔。 |
| 帳號專用檔 | 依檔首辨認。`DRM1.`、`DRMG1.`、`DRMD1.` 各使用原帳號的鋼琴、吉他、鼓譜匯入工具。 |
| 原圖、PDF 或原件附件連結 | 原件用於看譜與轉錄。朋友交換的是數位譜，原件、私人筆記、練習紀錄與來源媒體另由曲主管理。 |

成功後從回覆的 `content[0].text` 讀取接收者副本的 `id`、`kind`、`url` 和 `duplicate`，交付自己的開譜連結。重試相同內容會找到同一個副本。工具回報連結失效時，請分享者重新提供有效交換連結；遇到登入或帳號切換，先確認接收者的連線。

曲主要求分享自己的譜時，以該曲 ID 呼叫 `drm_create_exchange_link({id})`，私下交付傳回的完整 URL。連結固定於建立時的譜面版本；持有者可以下載或匯入。曲主要求停止分享時用 `drm_revoke_exchange_link({id})`。撤銷後，已下載的檔案與已匯入的副本仍可使用。要分享後續校訂版，依曲主要求撤銷並重新建立連結。
